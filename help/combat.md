### Combat skills

- Melee: represent chance to hit in close combat.
- Missile: represent chance to hot in distance combat.
- Dodge: value from this skill decrease of attacking chance to hit. Heavy armor lower this skill. Light armor raise this skill.

### Skill Raise

- Each skill raise by [1-3] points.
- If character is particually well-suited to the skill raise by [2-3] points.
- Each skill can be raised only one time per level.
- Every character can raise 3 skills. If `Wits` is 40+ there is another one check. If `Wits` is 70+ there is one more.

## Skills list

### Melee

Chance to hit enemy in melee.

### Range

Chance to hot enemy on distance.

### Dodge

Substract from melee or ranged skills of attacker. Can't be raised - use only use as equipment bonus.

### History

Gain a forgotten knowledge.
- Chance to get knowledge from statue in dungeon. See ancient art.

#Special

## Ancient art

In dungeon you can meet statue. If you pass history skill check you can learn peace of ancient art. There is 100 ancient art pieces. If you get all of them - you win the game.
